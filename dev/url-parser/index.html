Decompose URLs into protocol, host, path, query params, and hash.

URL Parser

What it does

The URL Parser decomposes any valid URL into its individual components: protocol, hostname, port, path, query string, query parameters (as a table), and hash fragment. You can also inspect the reconstructed URL from the parsed parts.

How to use

  1. Paste a URL into the input field
  2. Click Parse (or press Enter)
  3. The tool displays each component in separate fields
  4. Query parameters are shown in a key/value table
  5. The reconstructed URL is shown at the bottom

Common use cases

  • Inspecting API endpoint URLs with complex query strings
  • Debugging OAuth redirect URIs
  • Verifying URL encoding of special characters
  • Breaking down URLs from logs for analysis
  • Understanding URL structure for documentation

Privacy

URL parsing happens entirely in your browser using the built-in URL API. No data is sent to any server.

Related tools

  • URL Encode/Decode — Encode or decode URL components
  • cURL to Code — Convert cURL commands to code

FAQ

Does it support relative URLs? No, only absolute URLs with a protocol (https://, http://, etc.) are supported.

Can it parse URLs with special characters? Yes, percent-encoded characters are automatically decoded in the appropriate fields.

Does it support internationalized domain names (IDN)? Yes, IDN hostnames (punycode) are supported.

Parser de URL

O que faz

O Parser de URL decompõe qualquer URL válida em seus componentes individuais: protocolo, hostname, porta, caminho, query string, parâmetros de consulta (como tabela) e fragmento hash.

Como usar

  1. Cole uma URL no campo de entrada
  2. Clique em Analisar (ou pressione Enter)
  3. A ferramenta exibe cada componente em campos separados
  4. Parâmetros de consulta são mostrados em uma tabela de chave/valor
  5. A URL reconstruída é exibida na parte inferior

Casos de uso comuns

  • Inspecionar URLs de endpoints de API com query strings complexas
  • Depurar URIs de redirecionamento OAuth
  • Verificar codificação URL de caracteres especiais
  • Decompor URLs de logs para análise
  • Entender estrutura de URL para documentação

Privacidade

A análise de URL acontece inteiramente no seu navegador usando a API URL nativa. Nenhum dado é enviado para nenhum servidor.

Ferramentas relacionadas

  • Codificar/Decodificar URL — Codifique ou decodifique componentes de URL
  • cURL para Código — Converta comandos cURL em código

Perguntas frequentes

Suporta URLs relativas? Não, apenas URLs absolutas com protocolo (https://, http://, etc.) são suportadas.

Consegue analisar URLs com caracteres especiais? Sim, caracteres percentualmente codificados são automaticamente decodificados nos campos apropriados.

Suporta nomes de domínio internacionalizados (IDN)? Sim, hostnames IDN (punycode) são suportados.
