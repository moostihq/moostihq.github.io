JSON to CSV

Convert JSON arrays to CSV spreadsheet format.

JSON to CSV Converter

What it does

Converts JSON arrays (arrays of objects) to CSV format, and CSV back to JSON. The tool automatically detects headers from JSON keys and creates a properly formatted CSV file.

How to use

  1. Paste your JSON array into the input area
  2. Click JSON → CSV to convert to CSV format
  3. Or paste CSV and click CSV → JSON to convert to JSON
  4. Copy the result

Common use cases

  • Exporting API data to spreadsheets
  • Converting database query results to CSV
  • Importing data into Excel or Google Sheets
  • Data transformation pipelines

Privacy

All conversion runs in your browser. Your data is never sent to any server.

Related tools

  • CSV to JSON — Convert CSV to JSON
  • JSON Formatter — Format and validate JSON

FAQ

What if my JSON has nested objects? Nested objects are flattened as JSON strings within the CSV cell.

Are special characters escaped in the CSV? Yes, values containing commas or quotes are properly quoted.

Does it support different CSV delimiters? Currently uses comma delimiter (standard CSV).

Conversor JSON para CSV

O que faz

Converte arrays JSON (arrays de objetos) para formato CSV e CSV de volta para JSON. A ferramenta detecta automaticamente cabeçalhos das chaves JSON e cria um arquivo CSV corretamente formatado.

Como usar

  1. Cole seu array JSON na área de entrada
  2. Clique em JSON → CSV para converter para formato CSV
  3. Ou cole CSV e clique em CSV → JSON para converter para JSON
  4. Copie o resultado

Casos de uso comuns

  • Exportar dados de API para planilhas
  • Converter resultados de consultas de banco de dados para CSV
  • Importar dados no Excel ou Google Sheets
  • Pipelines de transformação de dados

Privacidade

Todo o processamento roda no seu navegador. Seus dados nunca são enviados para nenhum servidor.

Ferramentas relacionadas

  • CSV para JSON — Converta CSV para JSON
  • Formatador JSON — Formate e valide JSON

Perguntas frequentes

E se meu JSON tiver objetos aninhados? Objetos aninhados são achatados como strings JSON dentro da célula CSV.

Caracteres especiais são escapados no CSV? Sim, valores contendo vírgulas ou aspas são corretamente citados.

Suporta diferentes delimitadores CSV? Atualmente usa delimitador de vírgula (CSV padrão).
