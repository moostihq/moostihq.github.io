CSS Beautifier & Minifier

What it does

The CSS Beautifier and Minifier formats messy or compressed CSS into clean, readable code or compresses it for production use. It handles standard CSS including media queries, keyframes, and custom properties.

How to use

  1. Paste your CSS into the input area
  2. Click Beautify to add proper indentation and line breaks
  3. Click Minify to strip all whitespace and comments
  4. Copy the result with the Copy button

Common use cases

  • Formatting minified CSS from a CDN for debugging
  • Minifying hand-written CSS before deployment
  • Cleaning up generated CSS from preprocessors
  • Code review preparation with consistent formatting

Privacy

All processing runs in your browser. Your code is never sent to any server.

Related tools

  • HTML Beautifier — Format HTML code
  • SCSS Beautifier — Format SCSS stylesheets
  • LESS Beautifier — Format LESS stylesheets

FAQ

Does it support CSS variables? Yes, custom properties (CSS variables) are preserved correctly.

Does it handle vendor prefixes? Yes, vendor-prefixed properties are formatted like any other property.

What about media queries? Media queries are fully supported and properly nested on beautify.

Embelezador e Minificador CSS

O que faz

O Embelezador e Minificador CSS formata CSS bagunçado ou comprimido em código limpo e legível, ou o comprime para uso em produção. Suporta CSS padrão incluindo media queries, keyframes e propriedades customizadas.

Como usar

  1. Cole seu CSS na área de entrada
  2. Clique em Embelezar para adicionar indentação e quebras de linha adequadas
  3. Clique em Minificar para remover todos os espaços e comentários
  4. Copie o resultado com o botão Copiar

Casos de uso comuns

  • Formatar CSS minificado de uma CDN para depuração
  • Minificar CSS escrito à mão antes do deploy
  • Limpar CSS gerado por pré-processadores
  • Preparação para revisão de código com formatação consistente

Privacidade

Todo o processamento roda no seu navegador. Seu código nunca é enviado para nenhum servidor.

Ferramentas relacionadas

  • Embelezador HTML — Formate código HTML
  • Embelezador SCSS — Formate folhas SCSS
  • Embelezador LESS — Formate folhas LESS

Perguntas frequentes

Suporta variáveis CSS? Sim, propriedades customizadas (variáveis CSS) são preservadas corretamente.

Trata prefixos de fornecedor? Sim, propriedades com prefixo são formatadas como qualquer outra propriedade.

E as media queries? Media queries são totalmente suportadas e corretamente aninhadas ao embelezar.
