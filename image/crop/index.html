Image Cropper

Crop images to any size using a visual drag interface or precise pixel inputs — all in your browser with no file uploads required. Supports multiple aspect ratios including 1:1, 4:3, 16:9, and 3:2.

How to Use

  1. Drop, paste, or select an image.
  2. Choose an aspect ratio (or leave it on Free for unconstrained cropping).
  3. Drag on the canvas to define your crop area, or type exact pixel values in the X, Y, W, H inputs.
  4. Click Crop & Download to save the result.

Visual Crop Interface

The crop area is shown with a semi-transparent overlay outside the selection and a blue border inside it. Drag on the canvas to draw a new crop area at any time. The numeric inputs below the canvas always stay in sync with the visual selection.

Aspect Ratio Presets

RatioCommon uses
FreeAny size, unrestricted
1:1Instagram posts, avatars, profile pictures
4:3Classic photo prints, standard displays
16:9YouTube thumbnails, desktop wallpapers, presentations
3:2DSLR camera native ratio, photo prints

When you choose an aspect ratio, the height is automatically adjusted to match the selected width using height = width / aspect.

Pixel Inputs

For precise control, enter exact coordinates directly:

  • X — horizontal offset from the left edge
  • Y — vertical offset from the top edge
  • W — width of the crop region
  • H — height of the crop region

All values are clamped to stay within the image boundaries. The crop area will never extend beyond the image edges.

Tips

  • Straighten before cropping — use the Rotate tool first if your image is slightly tilted.
  • 1:1 crops for social media — most platforms require square thumbnails; use 1:1 with center positioning.
  • Crop then compress — reduce the canvas to just the area you need before compressing to maximise savings.
  • Number inputs on mobile — if drag handles are hard to use on small screens, type values directly into the pixel inputs.

Privacy

Your image never leaves your device. All cropping is performed locally using the HTML5 Canvas API.

Cortador de Imagem

Recorte imagens em qualquer tamanho usando uma interface visual de arrastar ou entradas precisas em pixels — tudo no seu navegador, sem necessidade de upload. Suporta múltiplas proporções, incluindo 1:1, 4:3, 16:9 e 3:2.

Como Usar

  1. Solte, cole ou selecione uma imagem.
  2. Escolha uma proporção (ou deixe em Livre para recorte sem restrições).
  3. Arraste no canvas para definir a área de recorte, ou digite valores exatos em pixels nos campos X, Y, L, A.
  4. Clique em Recortar e Baixar para salvar o resultado.

Interface Visual de Recorte

A área de recorte é exibida com uma sobreposição semitransparente fora da seleção e uma borda azul dentro dela. Arraste no canvas para desenhar uma nova área de recorte a qualquer momento. Os campos numéricos abaixo do canvas sempre ficam sincronizados com a seleção visual.

Proporções Predefinidas

ProporçãoUsos comuns
LivreQualquer tamanho, sem restrição
1:1Posts do Instagram, avatares, fotos de perfil
4:3Impressões fotográficas clássicas, monitores padrão
16:9Miniaturas do YouTube, papéis de parede, apresentações
3:2Proporção nativa de câmeras DSLR, impressões fotográficas

Quando você escolhe uma proporção, a altura é ajustada automaticamente para corresponder à largura selecionada usando altura = largura / proporção.

Entradas em Pixels

Para controle preciso, insira coordenadas exatas diretamente:

  • X — deslocamento horizontal a partir da borda esquerda
  • Y — deslocamento vertical a partir da borda superior
  • L — largura da região de recorte
  • A — altura da região de recorte

Todos os valores são limitados para permanecer dentro dos limites da imagem. A área de recorte nunca vai além das bordas da imagem.

Dicas

  • Endireite antes de recortar — use a ferramenta Girar primeiro se sua imagem estiver levemente inclinada.
  • Recortes 1:1 para redes sociais — a maioria das plataformas requer miniaturas quadradas; use 1:1 com posicionamento centralizado.
  • Recorte depois comprima — reduza o canvas apenas para a área necessária antes de comprimir para maximizar a economia.
  • Campos numéricos no celular — se as alças de arrastar forem difíceis de usar em telas pequenas, digite os valores diretamente nos campos de pixels.

Privacidade

Sua imagem nunca sai do dispositivo. Todo o recorte é realizado localmente usando a API Canvas do HTML5.

Recadrage d’Image

  3. Glissez sur le canvas pour définir la zone de recadrage, ou entrez les valeurs exactes.

Обрезка Изображений

Обрезайте изображения до любого размера с помощью визуального интерфейса перетаскивания или точного ввода пикселей — прямо в браузере, без загрузки. Поддерживает соотношения 1:1, 4:3, 16:9 и 3:2.

Как Пользоваться

  1. Перетащите, вставьте или выберите изображение.
  2. Выберите соотношение сторон (или оставьте «Свободное»).
  3. Перетащите на холсте, чтобы задать область обрезки, или введите точные значения.
  4. Нажмите Обрезать и Скачать для сохранения результата.

Соотношения Сторон

СоотношениеЧастые случаи
СвободноеЛюбой размер
1:1Посты Instagram, аватары
4:3Классические фотоотпечатки
16:9Миниатюры YouTube, презентации
3:2Нативное соотношение DSLR

Ввод в Пикселях

Для точного управления введите координаты: X (смещение по горизонтали), Y (по вертикали), Ш (ширина), В (высота). Значения ограничены границами изображения.

Советы

  • Выровняйте перед обрезкой — используйте инструмент Поворот, если изображение слегка наклонено.
  • Обрезка 1:1 для соцсетей — большинство платформ требуют квадратные миниатюры.

Конфиденциальность

Ваше изображение никогда не покидает устройство. Вся обрезка выполняется локально.

图片裁剪工具

通过可视化拖拽界面或精确像素输入裁剪图片至任意尺寸 — 所有操作在浏览器中完成，无需上传。支持 1:1、4:3、16:9 和 3:2 等多种比例。

使用方法

  1. 拖放、粘贴或选择一张图片。
  2. 选择宽高比（或选择”自由”进行无限制裁剪）。
  3. 在画布上拖动定义裁剪区域，或输入精确像素值。
  4. 点击裁剪并下载保存结果。

宽高比预设

比例常见用途
自由任意尺寸，无限制
1:1Instagram 帖子、头像
4:3经典照片冲印
16:9YouTube 缩略图、演示文稿
3:2单反相机原生比例

像素输入

精确控制请直接输入坐标：X（水平偏移）、Y（垂直偏移）、W（宽度）、H（高度）。所有值受图片边界限制。

使用建议

  • 先旋转再裁剪 — 如果图片略有倾斜，先使用旋转工具。
  • 社交媒体用 1:1 — 大多数平台需要方形缩略图。

隐私

您的图片不会离开设备。所有裁剪操作均在本地完成。

画像切り抜きツール

ドラッグ操作またはピクセル単位の精密入力で画像を任意のサイズに切り抜き — すべてブラウザ内で完結、アップロード不要。1:1、4:3、16:9、3:2のアスペクト比に対応。

使い方

  1. 画像をドロップ、貼り付け、または選択。
  2. アスペクト比を選択（自由切り抜きの場合は「自由」のまま）。
  3. キャンバス上でドラッグして切り抜き領域を定義、またはピクセル値を直接入力。
  4. 切り抜いてダウンロード をクリックして結果を保存。

アスペクト比プリセット

比率よく使う場面
自由任意のサイズ、制限なし
1:1Instagram投稿、アイコン
4:3クラシックな写真印刷
16:9YouTubeサムネイル、プレゼン
3:2DSLRカメラの原生比率

ピクセル入力

精密に制御するには座標を直接入力：X（水平オフセット）、Y（垂直オフセット）、W（幅）、H（高さ）。値は画像の境界内に制限されます。

コツ

  • 切り抜く前に回転を — 画像が少し傾いている場合は、まず回転ツールを使用。
  • SNSには1:1切り抜き — ほとんどのプラットフォームは正方形のサムネイルを要求。

プライバシー

画像はデバイスから一切送信されません。すべての切り抜き処理はローカルで行われます。
