Image Compressor

Reduce image file sizes directly in your browser — no upload, no server, complete privacy. Our image compressor lets you fine-tune quality and choose your output format with a real-time before/after preview.

How It Works

When you drop or paste an image, it is decoded using the browser’s built-in createImageBitmap API and drawn onto an HTML5 canvas. The canvas toBlob method then re-encodes the image at your chosen quality level, applying lossy compression that discards perceptually redundant data.

Quality Slider

The quality slider controls the compression level from 1 (maximum compression, lowest quality) to 100 (minimum compression, highest quality). A quality setting of 75–85 is a good starting point for most photographs — you get a significant file size reduction while the image still looks sharp to the human eye.

Format Options

  • Same as input — keeps the original format. Ideal when you just want smaller JPEG or WebP files.
  • JPEG — the most widely supported format for photographs. Not suitable for images requiring transparency.
  • WebP — modern format developed by Google that typically achieves 25–35% smaller files than JPEG at equivalent quality. Supported by all modern browsers.

When to Use Each Format

Use caseRecommended format
Photographs for webWebP or JPEG
Screenshots with textPNG (use the resize tool first)
Icons and logosPNG or SVG
Email attachmentsJPEG at quality 80

Understanding the Savings Indicator

The savings display shows original size, compressed size, and percentage change. A negative percentage (green) means the output is smaller. A positive percentage (red) means compression actually made the file larger — this can happen when converting a heavily-compressed JPEG to WebP at very high quality settings.

Tips for Best Results

  1. Start with quality 80 and lower only if the file is still too large.
  2. Try WebP — it often beats JPEG significantly.
  3. Avoid re-compressing JPEGs at low quality; each round of compression introduces more artefacts.
  4. PNG files are losslessly encoded; compressing them as JPEG will reduce size but add artefacts, especially around sharp edges.

Privacy

Your images never leave your browser. All processing happens locally using Web APIs. No files are transmitted to any server.

Compressor de Imagem

Reduza o tamanho de arquivos de imagem diretamente no seu navegador — sem upload, sem servidor, com total privacidade. Nosso compressor permite ajustar a qualidade e escolher o formato de saída com uma prévia em tempo real antes/depois.

Como Funciona

Quando você solta ou cola uma imagem, ela é decodificada usando a API createImageBitmap do navegador e desenhada em um canvas HTML5. O método toBlob do canvas então reencoda a imagem no nível de qualidade escolhido, aplicando compressão com perda que descarta dados perceptualmente redundantes.

Controle de Qualidade

O controle deslizante de qualidade vai de 1 (máxima compressão, menor qualidade) a 100 (mínima compressão, maior qualidade). Uma configuração de qualidade entre 75–85 é um bom ponto de partida para fotografias — você obtém uma redução significativa no tamanho enquanto a imagem continua nítida ao olho humano.

Opções de Formato

  • Mesmo do original — mantém o formato original. Ideal para reduzir arquivos JPEG ou WebP existentes.
  • JPEG — formato mais amplamente suportado para fotografias. Não suporta transparência.
  • WebP — formato moderno desenvolvido pelo Google que tipicamente gera arquivos 25–35% menores que JPEG com qualidade equivalente. Suportado por todos os navegadores modernos.

Quando Usar Cada Formato

UsoFormato recomendado
Fotografias para webWebP ou JPEG
Capturas de tela com textoPNG
Ícones e logotiposPNG ou SVG
Anexos de e-mailJPEG com qualidade 80

Entendendo o Indicador de Economia

O painel de economia mostra o tamanho original, o comprimido e a variação percentual. Um percentual negativo (verde) significa que a saída é menor. Um positivo (vermelho) significa que a compressão aumentou o arquivo — isso pode ocorrer ao converter JPEG já muito comprimido para WebP com qualidade muito alta.

Dicas para Melhores Resultados

  1. Comece com qualidade 80 e reduza apenas se o arquivo ainda estiver grande.
  2. Experimente WebP — geralmente supera o JPEG.
  3. Evite recomprimir JPEGs repetidamente em qualidade baixa; cada rodada de compressão adiciona mais artefatos.
  4. Arquivos PNG são codificados sem perda; comprimi-los como JPEG reduz o tamanho mas adiciona artefatos, especialmente em bordas nítidas.

Privacidade

Suas imagens nunca saem do navegador. Todo o processamento acontece localmente usando APIs Web. Nenhum arquivo é transmitido para qualquer servidor.

图片压缩工具

直接在浏览器中减小图片文件大小 — 无需上传，无需服务器，完全保护隐私。通过实时预览调整质量和输出格式。

工作原理

图片通过浏览器内置 API 解码，并在 HTML5 Canvas 上以所选质量重新编码，应用有损压缩去除视觉冗余数据。

质量控制

质量滑块从 1（最大压缩）到 100（最高质量）。75–85 是大多数照片的良好起点。

格式选项

  • 与输入相同 — 保持原始格式，适合只需缩小 JPEG 或 WebP 文件。
  • JPEG — 最广泛支持的照片格式，不支持透明度。
  • WebP — 现代格式，通常比同等质量的 JPEG 小 25–35%，所有现代浏览器均支持。

使用建议

  1. 从质量 80 开始，文件仍然过大时再降低。
  2. 尝试 WebP — 通常明显小于 JPEG。
  3. 避免低质量重复压缩 JPEG — 每次压缩都会增加伪影。

隐私

您的图片不会离开浏览器。所有处理均在本地完成。

画像圧縮ツール

仕組み

画像をドロップまたは貼り付けると、HTML5キャンバス上で選択した品質レベルで再エンコードされ、知覚的に冗長なデータを除去する非可逆圧縮が適用されます。

品質スライダー

品質スライダーは1（最大圧縮）から100（最高品質）まで設定できます。75〜85はほとんどの写真に適した出発点です。

フォーマット

  • 元の形式と同じ — 元の形式を維持。JPEGやWebPの縮小に最適。
  • JPEG — 写真で最も広くサポートされる形式。透明度非対応。
  • WebP — Google開発の現代的形式。同品質のJPEGより25〜35%小さく、すべてのモダンブラウザに対応。

コツ

  1. まず品質80から始め、ファイルがまだ大きい場合のみ下げる。
  2. WebPを試す — JPEGより大幅に小さくなることが多い。
  3. 低品質でのJPEG再圧縮は避ける — 毎回アーティファクトが増える。

プライバシー
