Image Resizer

Resize any image to exact pixel dimensions or by percentage — all in your browser, no upload needed. Supports JPEG, PNG, and WebP output with optional aspect ratio locking.

How It Works

After dropping or pasting your image, the tool decodes it into an ImageBitmap and renders it onto a live preview canvas. When you click Download, it draws the image at your specified dimensions using the canvas drawImage API and exports the result as your chosen format.

Setting Dimensions

Enter the target width and height in pixels. With aspect ratio lock enabled (the padlock button), changing the width automatically updates the height to preserve the original proportions — and vice versa.

Preset Sizes

Quick-access presets are provided for common targets:

  • 1920×1080 — Full HD, ideal for presentations and desktop wallpapers
  • 1280×720 — HD, great for video thumbnails and social media headers
  • 50% — half the original dimensions, useful for quick size reduction
  • 25% — quarter size, ideal for thumbnails and previews

Aspect Ratio Lock

The lock button keeps the width-to-height ratio constant. When locked and you type a new width, the height is recalculated automatically using the formula new_height = original_height × (new_width / original_width).

Tips

  • Enlarge with caution — upscaling increases pixel count but cannot recover lost detail. The result may look blurry.
  • Use PNG for graphics with sharp edges — JPEG introduces blocky artefacts around text and logos.
  • Combine with compress — resize first to the target dimensions, then compress to reduce file size further.
  • WebP offers smaller files than JPEG or PNG at similar quality for most use cases.

Privacy

No image data is sent to any server. All processing happens locally using the HTML5 Canvas API and Web Workers built into your browser.

Redimensionador de Imagem

Redimensione qualquer imagem para dimensões exatas em pixels ou por porcentagem — tudo no seu navegador, sem necessidade de upload. Suporta saída em JPEG, PNG e WebP com bloqueio opcional de proporção.

Como Funciona

Após soltar ou colar sua imagem, a ferramenta a decodifica em um ImageBitmap e a renderiza em um canvas de prévia ao vivo. Quando você clica em Baixar, ela desenha a imagem nas dimensões especificadas usando a API drawImage do canvas e exporta o resultado no formato escolhido.

Definindo Dimensões

Digite a largura e altura alvo em pixels. Com o bloqueio de proporção ativado (o botão de cadeado), alterar a largura atualiza automaticamente a altura para preservar as proporções originais — e vice-versa.

Tamanhos Predefinidos

Predefinições de acesso rápido são fornecidas para alvos comuns:

  • 1920×1080 — Full HD, ideal para apresentações e papéis de parede
  • 1280×720 — HD, ótimo para miniaturas de vídeo e cabeçalhos de redes sociais
  • 50% — metade das dimensões originais, útil para redução rápida de tamanho
  • 25% — tamanho de um quarto, ideal para miniaturas e prévias

Formatos de Saída

Bloqueio de Proporção

O botão de cadeado mantém a proporção largura-altura constante. Quando bloqueado e você digita uma nova largura, a altura é recalculada automaticamente usando a fórmula nova_altura = altura_original × (nova_largura / largura_original).

Dicas

  • Amplie com cautela — ampliar aumenta a contagem de pixels mas não recupera detalhes perdidos. O resultado pode ficar desfocado.
  • Use PNG para gráficos com bordas nítidas — JPEG introduz artefatos em blocos ao redor de texto e logotipos.
  • Combine com compressor — redimensione primeiro para as dimensões alvo, depois comprima para reduzir ainda mais o tamanho.
  • WebP oferece arquivos menores que JPEG ou PNG com qualidade similar para a maioria dos casos de uso.

Privacidade

Nenhum dado de imagem é enviado para qualquer servidor. Todo o processamento acontece localmente usando a API Canvas HTML5 integrada ao seu navegador.

Изменение Размера Изображений

Изменяйте размер изображений до точных размеров в пикселях или в процентах — прямо в браузере, без загрузки. Поддерживает вывод в JPEG, PNG и WebP с опциональной блокировкой пропорций.

Как Это Работает

После загрузки изображения инструмент декодирует его и отображает на канвасе. При нажатии «Скачать» изображение перерисовывается с указанными размерами и экспортируется в выбранном формате.

图片调整大小工具

将图片调整为精确的像素尺寸或按百分比缩放 — 所有操作在浏览器中完成，无需上传。支持 JPEG、PNG 和 WebP 输出，可选锁定宽高比。

工作原理

放入图片后，工具会将其解码并显示在预览画布上。点击下载时，以指定尺寸重新绘制并导出为您选择的格式。

设置尺寸

输入目标宽度和高度（像素）。启用宽高比锁定（锁按钮）后，修改宽度会自动调整高度以保持原始比例。

预设尺寸

  • 1920×1080 — 全高清，适合演示和壁纸
  • 1280×720 — 高清，适合视频缩略图
  • 50% — 原始尺寸的一半，快速缩小
  • 25% — 四分之一，适合缩略图和预览

输出格式

使用建议

  • 谨慎放大 — 放大无法恢复丢失的细节，结果可能模糊。
  • 含锐利边缘的图形用 PNG — JPEG 会在文字周围产生伪影。
  • 配合压缩使用 — 先调整大小，再压缩。

隐私

图片数据不会发送到任何服务器。所有处理均在本地完成。

画像リサイズツール

ブラウザで直接画像をピクセル単位またはパーセントでリサイズ — アップロード不要。JPEG、PNG、WebP出力に対応、アスペクト比固定も可能。

仕組み

画像をドロップすると、デコードしてキャンバスにプレビュー表示します。ダウンロード時に指定した寸法で再描画し、選択した形式でエクスポートします。

寸法の設定

ピクセル単位で目標の幅と高さを入力します。アスペクト比ロック（鍵ボタン）を有効にすると、幅を変更すると高さが自動的に調整されます。

プリセットサイズ

  • 1280×720 — HD、動画サムネイルやSNSヘッダーに
  • 50% — 元の寸法の半分、手軽な縮小に
  • 25% — 4分の1、サムネイルやプレビューに

コツ

  • 拡大は慎重に — 拡大しても失われたディテールは回復できません。
  • シャープなエッジのある図形にはPNGを — JPEGはテキスト周りにアーティファクトを生じます。
  • 圧縮と組み合わせる — 先にリサイズしてから圧縮を。
